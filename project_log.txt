    Record Format 
      separate internal record boundaries from DMA frame boundaries
      
      record0 | record1 | record2 | record3
      
      Each Record:
        Bytes	    Field
        0..1	    Sync
        2	        Version
        3	        Source ID
        4	        Payload type
        5	        Flags
        6..9	    Sequence count
        10..17	  Timestamp
        18..19	  Payload length
        20..23	  Payload info 0
        24..27	  Payload info 1
        28..59	  Payload area
        60..61	  CRC16
        62..63	  Reserved


     Pack many records into one larger DMA frame and 
     assert TLAST only at the end of that larger block.

      [HDR0][S...][HDR1][S...][HDR2][S...][HDR3][S...] TLAST

Sensors → Interfaces → FPGA acquisition/DSP → mission/control logic → communications/storage/actuators

split Project Alpha into these major subsystems:

1. Sensor and payload side
Cameras, IMU, environmental sensors, ADC-based science payloads.
2. FPGA real-time processing side
AXI Stream pipelines, filters, packet parsers, feature extraction, timing-critical logic.
3. Control and autonomy side
ARM/RPU software, mission sequencing, register control, fault handling.
4. Communications side
Ethernet first, then higher-speed serial/transceiver-based links.
5. Storage and telemetry side
DDR buffering, packetization, logging, transfer to host/ground station.
6. Verification and debug side
Testbench, loopback modes, built-in counters, status registers, ILA.
